# Google Machine Learning Crash Course

Seven notebooks cover regression, classification, numerical data and fairness,
followed by a participant-level evaluation example. All seven have saved runs
in the 25 October 2026 review.

| Notebook | Focus |
|---|---|
| [Taxi regression](01_linear_regression_taxi.ipynb) | Linear regression and evaluation; setup includes the `google-ml-edu` import repair |
| [Rice classification](02_binary_classification_rice.ipynb) | Binary classification |
| [Numerical statistics](03_numerical_data_statistics.ipynb) | Examining numerical features |
| [Bad values](04_numerical_data_bad_values.ipynb) | Data-quality problems |
| [Income fairness](05_fairness_income_colab.ipynb) | TensorFlow MinDiff |
| [Portable fairness companion](05b_fairness_portable.ipynb) | A separate PyTorch MMD adaptation |
| [Participant-level evaluation](06_subject_independent_evaluation.ipynb) | Grouped tuning, training-only preprocessing and leave-one-subject-out testing on synthetic data |

Use the [work index](../WORK_INDEX.md#google-mlcc) to open saved outputs. The
[run guide](../RUN_ORDER.md#google-mlcc) explains the separate fairness
environment. These runs do not establish completion of provider quizzes or
interactive activities.

Original material comes from [Google MLCC](https://developers.google.com/machine-learning/crash-course).
Local companions and AI-assisted adaptations are identified in the
[source index](../EXERCISE_INDEX.md). The synthetic participant example checks
an evaluation procedure; it does not establish performance on physiological data.
