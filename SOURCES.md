# Sources and data

The notebooks draw on the courses below. The [source index](EXERCISE_INDEX.md)
and [exercise manifest](exercise_manifest.json) distinguish original course
material from shorter companions and local adaptations. Revisions are pinned
where available. Original licence notices remain with the code; no replacement
licence applies to the whole collection.

## Course material

| Resource | Original material |
|---|---|
| Google MLCC | [Programming exercises](https://github.com/google/eng-edu/tree/main/ml/cc/exercises) |
| MIT 6.S191 | [Introduction to Deep Learning labs](https://github.com/MITDeepLearning/introtodeeplearning) |
| fast.ai Part 1 | [Practical Deep Learning for Coders](https://github.com/fastai/course22) |
| fastbook | [Book notebooks](https://github.com/fastai/fastbook), including MNIST and collaborative filtering |
| fast.ai Part 2 | [From Deep Learning Foundations to Stable Diffusion](https://github.com/fastai/course22p2) |
| Diffusion introductions | [fast.ai diffusion notebooks](https://github.com/fastai/diffusion-nbs) |

The synthetic wearable and signal-processing companions are local, AI-assisted
adaptations. Their results illustrate methods and evaluation choices; they are
not replications of published physiological benchmarks. The Part 1
[attribution note](03_fastai/ATTRIBUTION.md) gives more detail about that material.

| Data | Source |
|---|---|

| Irish ABC music | The official [mitdeeplearning 0.7.5 package](https://pypi.org/project/mitdeeplearning/0.7.5/) |
| Titanic companion data | [Seaborn's public teaching copy](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv) |
| MovieLens 100K | [GroupLens](https://grouplens.org/datasets/movielens/100k/) |

The bad-values example uses data embedded in Google's notebook. Wearable
signals, signal-processing examples and image setup patterns are generated by
the included code with seed 42. The short Titanic companion uses a public
teaching copy, separate from the original competition tables used by the full
course exercises.

Some public teaching files are downloaded on demand. Competition datasets and
restricted ImageNet data need their own access. See [RUN_ORDER.md](RUN_ORDER.md)
for the files each exercise needs.
